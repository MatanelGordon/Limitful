# Limitful for Go

The primary `limitful` package lives at this module root, matching its public
import path:

```go
import "github.com/MatanelGordon/Limitful/go"
```

Future Go packages use normal subdirectories, such as `opentelemetry/` or
`redissynchronization/`. The name `main` is reserved for executable packages and
is not used as a library container.
